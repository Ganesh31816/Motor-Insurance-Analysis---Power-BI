# 🚗 Vehicle Insurance Management System – MySQL & Power BI

## 📌 Project Overview

A data management and analytics project for managing **customers, vehicles, insurance policies, and claims** using MySQL and Power BI.

The project provides interactive dashboards to analyze **policies, premium revenue, vehicles, customers, and claims**.

---

## 🎯 Objectives

- Manage customer and vehicle data
- Manage insurance policies
- Track policy status and renewals
- Analyze premium revenue
- Analyze insurance claims and payouts
- Create interactive Power BI dashboards

---

## 🛠️ Technologies

- **MySQL** – Database
- **SQL** – Data analysis
- **Power BI** – Dashboard
- **Power Query** – Data transformation
- **DAX** – Calculations
- **GitHub** – Version control

---

## 🗄️ Database Tables

- **Customers** – Customer details
- **Vehicles** – Vehicle details
- **Policy_Plan** – Insurance plan details
- **Active_Enrollments** – Policy information
- **Claims** – Insurance claim details
